# 🔐 02 - Cryptography

This category tests your ability to break classical and modern ciphers, analyze mathematical implementation flaws in crypto systems, and decrypt encrypted flags.

---

## 🗝️ Common Topics in picoCTF Cryptography:

1. **Classical Ciphers:**
   - Caesar Cipher (Rot13 / RotN)
   - Substitution Cipher
   - Vigenère Cipher

2. **Public Key Cryptography:**
   - **RSA**: Common flaws (Small $e=3$, Factoring modulus $N$, Common Modulus attack, Wiener's attack).
   - Diffie-Hellman Key Exchange.

3. **Symmetric & Bitwise Ciphers:**
   - XOR Ciphers ($A \oplus B = C \implies A \oplus C = B$).
   - AES (Block Ciphers, ECB / CBC mode / IV reuse).

4. **Hash Functions:**
   - MD5, SHA1, SHA256, Length Extension Attacks.

---

## 🛠️ Recommended Tools:
- **CyberChef**: Interactive web application for encryption and decoding.
- **RsaCftTool**: Automated RSA exploitation tool.
- **SageMath**: Powerful mathematical environment for big number calculations and lattice attacks.
- **PyCryptodome**: Python library for AES, RSA, and XOR primitives.
